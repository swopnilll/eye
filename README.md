# Pooja Sharma Brows

A mobile-first website for Pooja Sharma's brow service in Caversham, Perth.

## Run locally

```bash
pnpm install
pnpm dev
```

## Build for production

```bash
pnpm build
pnpm start
```

Set `NEXT_PUBLIC_SITE_URL` to the production URL before deployment so canonical metadata and the sitemap point to the live site.
